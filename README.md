# Виджет банковских операций

Учебный Python-проект для обработки и безопасного отображения банковских данных. Программа умеет маскировать номера карт и счетов, форматировать даты, а также фильтровать и сортировать списки банковских операций.

## Технологии
- **Python 3.13+**
- **Poetry** — управление зависимостями и виртуальным окружением
- **Pytest** и **Pytest-cov** — модульное тестирование и анализ покрытия кода
- **Flake8**, **Mypy**, **Black**, **Isort** — проверка стиля кода, форматирование и статическая типизация

## Установка и запуск

1. Скопируйте репозиторий к себе на компьютер:
```bash
git clone git@github.com:ddubokk/homework_10_1.git
cd homework_10_1
```

2. Установите зависимости через Poetry:
```bash
poetry install
```

3. Запустите демонстрационный скрипт из корня проекта:
```bash
poetry run python main.py
```

## Описание модулей

1. **Маскировка карт и счетов (`src/masks.py`)** — функции `get_mask_card_number` и `get_mask_account` для скрытия номеров карт и банковских счетов.
2. **Форматирование данных (`src/widget.py`)** — функции `mask_account_card` и `get_date` для распознавания типа реквизитов и приведения дат к формату `ДД.ММ.ГГГГ`.
3. **Обработка операций (`src/processing.py`)** — функции `filter_by_state` и `sort_by_date` для фильтрации списков транзакций по статусу и сортировки по дате.

## Тестирование

Для проверки корректности работы всех функций проекта написаны модульные тесты с использованием фреймворка **pytest**, фикстур (`tests/conftest.py`) и параметризации (`@pytest.mark.parametrize`).

### Структура тестов
- `tests/conftest.py` — общие фикстуры с тестовыми наборами банковских операций.
- `tests/test_masks.py` — тесты для функций маскирования номеров карт и счетов (`src/masks.py`).
- `tests/test_widget.py` — тесты для функций обработки реквизитов и форматирования дат (`src/widget.py`).
- `tests/test_processing.py` — тесты для фильтрации и сортировки операций (`src/processing.py`).

### Запуск тестов и проверка покрытия
Для запуска всех тестов выполните команду:
```bash
poetry run pytest
```

Для запуска тестов с подсчетом покрытия кода и генерацией HTML-отчета выполните:
```bash
poetry run pytest --cov=src --cov-report=html
```
Текущее покрытие функционального кода (`src/`) тестами составляет **100%** (при минимальном требовании 80%). Актуальный HTML-отчет сохранен в директории `htmlcov/index.html`.
